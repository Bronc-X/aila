# toni.asia Brand Kit V1

This folder contains an original identity direction for `toni.asia`.

## Design Logic

- Symbol: a circular command route, Asia/time-zone orbit, and negative-space `T`.
- Wordmark: lowercase `toni.asia` with a disciplined multicolor letter rhythm.
- References translated, not copied: geometric developer-tool clarity plus friendly multicolor lettering.
- Tagline: `build in motion`.

## Files

- `toni-asia-mark.svg`: primary symbol.
- `toni-asia-logo-full.svg`: full logo lockup.
- `toni-asia-wordmark.svg`: wordmark only.
- `toni-asia-icon.svg`: favicon/app icon candidate.
- `toni-asia-brand-board.svg`: VI overview board.
- `toni-asia-mark-v2.svg`: revised developer-tool mark with segmented blocks.
- `toni-asia-logo-full-v2.svg`: revised full lockup with a terminal-style wordmark.
- `toni-asia-brand-board-v2.svg`: revised VI board, less Google-like and closer to modular code-tool DNA.

## Usage Notes

Use the full logo on warm ivory or white backgrounds. Use the icon on dark product surfaces, app shortcuts, favicon tests, and compact social previews. Keep plenty of whitespace around the mark.

## V2 Direction

V2 reduces the multicolor wordmark because V1 read too close to Google. The primary system is now graphite, warm orange, and ivory. The Claude Code reference is translated through segmented rectangular modules, terminal contrast, and a block-built `T`, without copying the original Claude Code mark.
