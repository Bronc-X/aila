# toni.asia Logo / VI 设计需求文档

## 1. 项目背景

`toni.asia` 是 Toni 的个人品牌与作品入口，承载 AI 产品实验、个人项目展示、工具发布、内容沉淀和未来商业合作。它不只是一个个人主页，也不是普通作品集，更像一个「AI builder / product operator」的长期工作台。

本次设计目标是为 `toni.asia` 设计一套可长期使用的 Logo 与基础 VI 系统，用于官网、社交头像、favicon、项目封面、名片、演示文档和未来产品子品牌延展。

## 2. 核心目标

设计一套原创、克制、开发者气质强的 `toni.asia` 品牌识别系统。

它应该让人联想到：

- AI builder
- developer tool
- command line / terminal
- modular system
- Asia-facing product lab
- 快速构建、持续发布、工程感、个人但不随意

它不应该像：

- 搜索引擎品牌
- 彩虹消费互联网 Logo
- 普通个人博客 Logo
- Web3 / NFT 风格图标
- 泛 AI 渐变球、光圈、星星、机器人

## 3. 品牌关键词

建议围绕以下关键词展开设计：

| 维度 | 关键词 |
|---|---|
| 气质 | 冷静、聪明、工程化、克制、可信 |
| 行为 | build、ship、iterate、operate |
| 视觉 | 终端、代码块、命令框、模块、路径、构件 |
| 情绪 | 有掌控感，但不冷冰冰 |
| 地域感 | Asia-facing，但不要做东方符号堆砌 |

## 4. 参考方向

### 4.1 可参考 Claude Code 的部分

可以借鉴 Claude Code 一类开发者工具品牌的「气质」，包括：

- 黑底或深色产品界面
- 温暖橙色作为主识别色
- 分段矩形 / 模块化图形
- 像终端、代码块、命令面板一样的工程感
- 简洁、硬朗、可缩放的图形符号

但不能直接复制：

- Claude / Anthropic 的具体图形结构
- 现成 Logo 的比例、轮廓、构图
- 完全相同的色彩组合和图标语义

### 4.2 可参考 Google 的部分

可以借鉴 Google 的「友好、清晰、字母识别度高」这一点。

但本项目已经验证：彩色字母过多会让 `toni.asia` 看起来太像 Google。因此：

- 不要把 `toni.asia` 做成 Google 式彩虹字标
- 不要每个字母都用红黄蓝绿
- 多色最多作为辅助系统，用于产品标签、分类、状态点
- 主 Logo 应以 1 个主色 + 中性色为核心

## 5. 推荐设计方向

### 方向 A：模块化 T 标

用多个圆角矩形或代码块组成一个抽象的 `T`。

特点：

- 一眼有 developer tool 感
- 适合 favicon、社交头像、app icon
- 可以延展成 pattern、loading、项目标签
- 与 Toni 的首字母直接相关

设计要点：

- `T` 不要太普通，要像被代码块、构件或命令单元搭起来
- 可以放在终端窗口、八边形 badge、命令框、卡片框里
- 小尺寸下仍然清楚

### 方向 B：命令框 / 路径符号

把 `toni.asia` 理解成一个持续 build/ship 的命令入口。

可以用：

- `$`
- cursor
- prompt input
- route / path
- command block
- bracket / frame

但这些元素应被抽象化，不要做成普通 terminal 截图。

### 方向 C：亚洲时间带 / 发布路径

可以从 `asia` 提取「从亚洲出发、面向全球发布」的隐喻。

可用方式：

- 路径线
- 坐标点
- 时间带 / orbit
- 地理方向感

禁忌：

- 不要使用龙、山水、印章、祥云等直白东方元素
- 不要做旅游品牌感

## 6. 色彩建议

主系统建议采用：

| 用途 | 颜色 | 说明 |
|---|---|---|
| 主背景 | `#12110F` | 深石墨黑，开发者工具感 |
| 面板背景 | `#1C1A17` | 比纯黑柔和 |
| 主识别色 | `#DF7652` | 温暖代码橙 |
| 次强调色 | `#F39A6B` | 用于 hover、辅助块 |
| 文字 / 纸张 | `#FAF4E8` | 暖白，避免冷白 |
| 辅助灰 | `#A99A8C` | 小字、说明、边界 |

辅助色可以保留少量红、黄、蓝、绿，但只用于分类和产品标签，不进入主字标。

## 7. 字体方向

建议使用两层字体策略：

1. Logo / 标题：monospace 或接近 monospace 的工程感字形
2. 正文 / 官网 UI：现代无衬线字体，保持可读性

可以探索：

- IBM Plex Mono
- JetBrains Mono
- Berkeley Mono 风格
- Space Mono
- Inter / system sans 作为正文搭配

注意：

- `toni.asia` 必须清晰可读
- 不要为了科技感牺牲识别
- 字距不要过度拉开

## 8. Logo 组成要求

至少需要设计以下版本：

1. 图形标：适合 favicon、头像、app icon
2. 横向完整 Logo：图形标 + `toni.asia`
3. 纯字标：只有 `toni.asia`
4. 深色背景版本
5. 浅色背景版本
6. 单色版本
7. 小尺寸测试版本

## 9. VI 应用场景

请至少展示以下应用：

- 官网首屏 header
- favicon / app icon
- 社交头像
- 项目封面卡片
- 演示文档封面
- 名片或联系卡
- 命令行 / terminal 风格应用
- 产品分类标签或 badge

## 10. 交付物

设计师最终需交付：

### 10.1 源文件

- Figma 文件
- 可编辑矢量 Logo
- 字体、颜色、间距规范

### 10.2 导出文件

- SVG：主 Logo、图形标、字标、单色版
- PNG：透明背景和深浅背景预览
- favicon：至少提供 `32x32`、`180x180`、`512x512`
- 社交头像：`1024x1024`
- 品牌板：横版或 3x3 overview board

### 10.3 说明文档

需说明：

- Logo 概念
- 图形构成逻辑
- 色彩规范
- 字体规范
- 最小尺寸
- 安全留白
- 禁用示例

## 11. 验收标准

设计通过需满足：

- 一眼不像 Google
- 有明显 developer tool / code tool 气质
- 能看出与 `Toni` 或 `toni.asia` 的关系
- 小尺寸下仍能识别
- 黑底和浅底都成立
- 字标清晰，不靠复杂解释才能读懂
- 图形足够原创，不接近 Claude / Google / Anthropic 的现有 Logo
- 可用于真实官网，不只是好看的 moodboard

## 12. 禁区

不要做：

- Google 式彩虹字母 Logo
- Claude Code 原图形的近似复刻
- AI 常见渐变球 / 星星 / 魔法棒
- 机器人头像
- 地球、亚洲地图、龙、祥云等直白符号
- 过度赛博朋克
- 纯黑白无个性的极简字标
- 复杂到 favicon 看不清的图形

## 13. 当前内部参考

当前已有两版内部探索，可作为讨论参考，不作为必须照抄的设计稿。

V1 问题：

- 字标过度接近 Google
- 图形偏通用几何，developer tool 感不足

V2 方向：

- 更接近目标
- 深色 + 橙色 + 暖白
- 模块化 `T`
- 命令行 / 代码块 / terminal 气质更强

请为 `toni.asia` 设计一套原创 Logo 与基础 VI：它是一个 AI builder 的个人品牌和产品实验室，视觉上应更接近开发者工具、终端、模块化代码块和持续 build/ship 的感觉；可以借鉴 Claude Code 的工程气质和 Google 的清晰友好，但不要像 Google 彩虹字标，也不要复刻 Claude / Anthropic 的图形。
