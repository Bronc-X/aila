# Toni Universe 回归基线

## 基线目标

本基线保护 `/toni-universe` 当前已经确认的 FDE 星系图谱体验，重点防止后续修改破坏业务关系、节点内容和核心交互。

## 受保护行为

- 图谱以 `Enterprise FDE` 为唯一核心业务，并保留发现、设计、构建、部署、运营、沉淀六个交付阶段。
- `/` 正式使用 FDE 星系图谱作为首页入口；原空间首页保留在 `/spatial`，不得误删旧功能。
- 首页左侧保持紧凑的作品集控制铭牌，不恢复成大字欢迎页或四等分仪表盘；标题固定为 `Toni 的主页`，继续保留已经确认的作品、工具、陪跑、联系与业务现场文案。
- 左侧铭牌继续提供当前视图、节点搜索、四层筛选和交付数量信息；视觉精简不得以删除这些功能为代价。
- 每个节点都有完整内容、独立地址，并至少参与一条真实业务关系。
- 业务关系不存在自连接和重复连接；每条关系都保留连续主线，避免视觉上出现未接通的线段。
- 神经元式放电纤维保留为装饰层，不作为业务关系连通性的判断依据。
- 鼠标滚轮由 GSAP 驱动相机远近移动，并限制在 OrbitControls 的安全距离范围内。
- 点击节点使用 GSAP 两段式镜头推进、视野收束、轻量 Bloom 与节点确认动画；快速连续点击时以前一次动画可被覆盖为准。
- 同一节点第一次点击只聚焦，第二次点击进入该节点映射的原有 Axure 子界面或既有作品页，例如 `/tools/research`、`/tools/admin`、`/tools/operations`、`/aila`、`/work/[slug]`。
- 原有子界面保留既有视觉与业务功能，只通过共享 GSAP 动画层升级页面入场、滚动显隐、滚回消失、落定清理和站内路由离场。
- `/toni-universe/[nodeId]` 节点档案页继续保留，作为“查看星系说明”的次级入口和未配置目标时的回退，不作为星系二次点击的默认去向。
- 节点档案页使用与主图谱一致的 GSAP 入场和路由离场节奏，并正确清理时间线。
- `prefers-reduced-motion` 用户获得立即完成的镜头切换，不被强制播放长动画。
- `/toni-universe/[nodeId]` 节点页展示精准说明、直接关系和可继续扩展的独立内容入口。
- `Taiga` 首页入口固定使用清晰的静态精灵帧，不得恢复自动循环播放或闪烁；进入 `/pet/taiga` 后的房间动画不受此限制。
- 航模入口继续使用项目专属的工程测量环飞行器徽记 `public/toni-universe/aeromodel-emblem-v2.png`，不得退回通用飞机图标、Emoji 或带棋盘格背景的伪透明素材。
- Taiga 与航模入口继续保留既有 GSAP 入场和悬停二次震动反馈，视觉降噪不得删除交互反馈或原有跳转。

## 统一命令

```powershell
npm run test:baseline
```

该命令会运行星系静态回归断言、项目既有基线测试、生产构建，并启动生产服务器检查主图谱和代表性节点详情页。任一检查失败时命令必须以非零状态退出。

## 未来修改规则

任何涉及以下文件或行为的修改，都必须在修改前后各运行一次 `npm run test:baseline`：

- `data/toni-universe.json`
- `app/toni-universe/`
- `public/toni-universe/aeromodel-emblem-v2.png`
- Three.js 场景、关系线、节点定位或相机参数
- GSAP 滚轮、点击、聚焦和高亮动画
- `app/components/LegacyPageMotionShell.tsx` 及接入该动画壳的原有子界面布局
- 节点详情页内容和关系呈现

不得为了让门禁通过而删除或弱化断言。若产品方向主动变化，应先更新受保护行为，再同步修改断言和本文档。

## 人工浏览器复核

自动门禁通过后，至少检查以下路径：

1. 打开 `/toni-universe`，确认所有业务关系主线从节点中心连续连接到目标节点。
2. 滚动鼠标滚轮，确认镜头平滑缩放、不穿过星系中心且没有页面误滚动。
3. 快速连续点击多个节点，确认镜头最终停在最后一次点击的节点。
4. 对“进入现场”再次点击，确认进入 `/tools/research`；对“进入生产”再次点击，确认进入 `/tools/admin`；对“持续运营”再次点击，确认进入 `/tools/operations`。
5. 对 `Enterprise FDE` 再次点击，确认进入 `/aila#cooperation`；作品类节点进入已有 `/work/[slug]` 或产品页面。
6. 在 `/tools/research`、`/tools/admin`、`/tools/operations`、`/aila` 和 `/work/training-system` 上向下与向上滚动，确认内容出现、落定、回滚消失自然，且站内链接离场动画正常。
7. 从详情面板点击“查看星系说明”，打开 `/toni-universe/fde` 或 `/toni-universe/deploy`，确认档案说明和直接关系仍正常展示。
8. 打开 `/spatial`，确认原空间首页仍可正常使用。
9. 检查浏览器控制台，不应出现运行时错误、WebGL 错误或未清理动画导致的异常。
10. 在首页停留至少 3 秒，确认 Taiga 图像保持稳定、不闪烁；悬停后仍有一次推进和轻微二次震动反馈。
11. 检查航模入口，确认显示专属飞行器工程徽记，轮廓清晰、背景透明，没有通用飞机图标或棋盘格底纹。
12. 检查左侧铭牌，确认标题、既有文案、搜索、四个筛选项和当前视图均存在，且铭牌没有遮挡主要星系节点。
