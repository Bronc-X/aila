# 设计语言规范

> 新建项目时，修改本文件以定义该项目的视觉系统。

## 色彩系统

- 背景色：`#FAF9F6`（暖白）/ `#FFFFFF`（纯白）
- 主边框：`#E5E1D8`
- 高亮边框（hover）：`#D97706`
- 品牌主色 / CTA：`#D97706`（琥珀橙）
- 卡片背景：`#F3F1ED`

## 文字层级

| 层级 | 色值 | 用途 |
|---|---|---|
| 标题/强调 | `#111111` | 页面标题、核心信息 |
| 正文 | `#444444` | 段落内容、描述文案 |
| 辅助信息 | `#666666` | 次要标签、小字 |
| 占位/禁用 | `#888888` | Placeholder、disabled 状态 |

## 按钮样式

- 主按钮：`bg-[#D97706] text-white`，hover 加深
- 次按钮：`bg-[#F3F1ED] text-[#444] border-[#E5E1D8]`

## 动效规范

- 引擎：Framer Motion
- 允许的属性：`opacity`, `y`, `x`, `scale`（克制使用）
- 弹簧配置：`spring` 类型，保持自然感
- 禁止：花哨旋转、3D 翻转、过度粒子效果

## 卡片与容器

- 绝不使用纯黑背景
- 保持空间呼吸感（充足 padding/gap）
- 圆角统一：`8px` 或 `12px`
